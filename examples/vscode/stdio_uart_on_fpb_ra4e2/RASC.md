# Renesas RA CMake Project

This project is generated by RASC.

###  Building via CLI:
Check CMakePresets.json file for preset configuration. Define related environment variables or create your own CMakeUserPresets.json file according to your own system. Required variables:

- RASC_EXE_PATH: Path of FSP Smart Configurator
- ARM_LLVM_TOOLCHAIN_PATH: Path of toolchain's binary directory
- If ninja is not in the PATH, CMAKE_MAKE_PROGRAM should point to the ninja executable file path

Configure: ```cmake --preset <config preset name>```

- Ex.: ```cmake --preset Debug```
- Ex.: ```cmake --preset Release```

Build: ```cmake --build --preset <build preset name>```
- Ex.: ```cmake --build --preset Debug```
- Ex.: ```cmake --build --preset Release```

### Configure via Visual Studio Code Presets
- Define related environment variables needed in CMakePresets.json or if Renesas Platform Extension is installed let it create CMakeUserPresets.json for your environment
- Select configure preset and click build in VS Code status bar


### Configure via Visual Studio Code Kits

- Set ARM_LLVM_TOOLCHAIN_PATH as an environment variable before starting VS code or alternatively set ARM_LLVM_TOOLCHAIN_PATH in .vscode/cmake-kits.json
- Set RASC_EXE_PATH, Path of FSP Smart Configurator
- Select "ARM_LLVM_TOOLCHAIN_PATH LLVM kit with toolchainFile" kit in VS Code status bar
- It is recommended to avoid spaces in the toolchain and project paths as they might be interpreted as delimiters by CMake and the other build tools.

Example:

```set ARM_LLVM_TOOLCHAIN_PATH=/your/toolchain/bin/path```
```set RASC_EXE_PATH=/your/smart/configurator/path```
```cd /your/project/location
```code .```
or alternatively,  ```code  your-code-workspace-file```
- Click build in VS Code status bar

### Switching to CMake Kits on VS Code
- Set "cmake.useCMakePresets" to "never" to enable Kits
- Set "cmake.useCMakePresets" to "always" to enable Presets
- Set "cmake.useCMakePresets" to "auto" to enable Presets when preset json files exist
